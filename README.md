# Polynor Landing Page

Polynor mahsulotlari va yechimlari uchun rasmiy professional lending sahifasi.

## 🌐 Sayt manzili (Live Demo)
- **Production URL:** [https://polynor.tajriba24.uz](https://polynor.tajriba24.uz)

## 🛠 Texnologiyalar
- **Frontend:** HTML5, CSS3, JavaScript
- **Web Server:** Caddy Server (avtomatik Let's Encrypt SSL/HTTPS)
- **Hosting:** Eskiz VPS (Ubuntu 24.04 LTS)

## 📂 Fayllar tuzilmasi
- `index.html` — Saytning asosiy bosh sahifasi
- `logo.png` — Brend logotipi
- `small_*.png` — Mahsulot va illyustratsiya rasmlari
- `run.sh` — Serverga avtomatlashtirilgan o'rnatish skripti

## 🚀 Serverga o'rnatish (Deploy)
Serverda loyihani ishga tushirish uchun quyidagi skript ishlatiladi:
```bash
curl -sL https://raw.githubusercontent.com/Dariko-HR-Marketing/Polynor/main/run.sh | bash
```
